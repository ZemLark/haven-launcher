# Haven

Haven is a game launcher for Windows, Mac and Linux: all your games from every launcher in one library, plus its own store, friends and chat.

This repository holds Haven's downloads and update files (see **Releases**). Installed copies of Haven check here for updates.

## Download (always the newest version)

- Windows: [HavenSetup.exe](https://github.com/ZemLark/haven-launcher/releases/latest/download/HavenSetup.exe)
- Mac with Apple silicon: [Haven-arm64.dmg](https://github.com/ZemLark/haven-launcher/releases/latest/download/Haven-arm64.dmg)
- Mac with Intel: [Haven-x64.dmg](https://github.com/ZemLark/haven-launcher/releases/latest/download/Haven-x64.dmg)
- Linux: [AppImage](https://github.com/ZemLark/haven-launcher/releases/latest/download/Haven-x86_64.AppImage) or [.deb](https://github.com/ZemLark/haven-launcher/releases/latest/download/Haven-amd64.deb)
